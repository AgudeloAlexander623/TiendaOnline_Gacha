# GearQuest Frontend

Frontend de GearQuest construido con React + TypeScript + Vite.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Arquitectura

Ver [documentation/FRONTEND_ARCHITECTURE.md](documentation/FRONTEND_ARCHITECTURE.md) para el esquema de arquitectura propuesto.
