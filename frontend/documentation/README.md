# Documentación Frontend - GearQuest

Esta carpeta está destinada a que cada desarrollador registre su documentación personal sobre los cambios realizados en el frontend.

## Uso

- Crear un archivo por desarrollador o por tarea (ej. `agude-changes.md`, `feature-auth-notes.md`)
- Describir cambios, decisiones, dudas, TODOs
- Mantener actualizado con lo que se vaya haciendo (sin tocar código ajeno)
- Seguir la norma: "no tocar código sin autorización"

## Estructura sugerida

```text
documentation/
├── README.md
├── FRONTEND_ARCHITECTURE.md  # Esquema arquitectura (este documento base)
└── personal/                 # Documentación individual (crear subcarpeta por dev)
```

## Notas

- No incluir secretos, tokens o datos sensibles
- Documentar solo lo relacionado al frontend
- Mantener conciso y claro
